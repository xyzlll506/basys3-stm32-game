# 项目阶段与后续计划

项目目标是用 Basys 3 生成 2D 彩色 VGA 游戏画面，STM32 NUCLEO-F413ZH 执行游戏状态和交互逻辑，双方通过 UART 交换状态。

当前代码只实现首次双板 UART 通信。下列待做项是开发顺序建议，不代表仓库中已经存在相应模块。

| 阶段 | 状态 | 达成条件 |
|---|---|---|
| 1. UART 初开发 | 源码、仿真和构建已完成；实体联调待做 | 两板连接后，电脑持续看到序号递增的 `PASS`，失败和复位后能够恢复 |
| 2. VGA 时序与测试画面 | 待做 | 生成 640×480 显示时序，在兼容显示器上稳定显示色条、边框和测试网格 |
| 3. 方块移动 | 待做 | 先在 FPGA 本地控制方块，再由 STM32 通过 UART 更新坐标，边界和更新时机正确 |
| 4. 角色与地图 | 待做 | 加入精灵 ROM、透明色、瓦片地图，确认存储资源和绘制优先级 |
| 5. 游戏规则 | 待做 | STM32 实现移动、跳跃、碰撞、死亡及重开；FPGA 根据状态绘制 |
| 6. 音效与完整展示 | 待做 | 根据现有器件增加提示音或可变音调音效，完成菜单、关卡和稳定性验证 |

## 下一步：在实体板上确认通信

按 [上手文档](getting-started.md) 断电接好三根线，分别下载两侧程序。先确认心跳灯，再打开 ST-LINK 虚拟串口检查 `PASS`。记录板卡版本、下载工具、现象及失败条件，作为实体测试结果补充到验证文档。

目前已经完成的 Keil 编译、XSim 仿真、Vivado 综合和布局布线不能替代这一步。

## VGA 阶段的硬件前提

需要带 VGA 输入、明确支持 640×480 约 60 Hz 输入的彩色显示设备，以及匹配的 VGA 线和供电。屏幕的原生分辨率可以更高，但必须确认输入模式和缩放行为。首次调试可以借用兼容显示器，尺寸不会改变 FPGA 所输出的分辨率。

已有的 7 英寸 MIPI-DSI 屏幕不能直接接入 Basys 3 VGA 插座；当前路线没有实现 DSI 桥接。显示设备尚未在本仓库中绑定具体采购型号。

## 软件扩展原则

先独立验证 VGA 图像，再接入串口坐标更新。图像显示采用扫描时序与图形组合绘制作为起点，是否需要帧缓存应根据后续画面与资源需求决定。

STM32 当前使用 16 MHz HSI 和轮询 HAL，只是通信入门配置。游戏阶段再根据逻辑频率、日志与串口负载调整时钟、接收方式和帧协议。坐标、输入、动画等消息应形成明确协议后，双方同步实现。

现有有源蜂鸣器可先用于固定音调提示；希望播放不同音调或简单旋律时，再考虑无源蜂鸣器及匹配驱动。音效不影响当前双板 UART 验证。
