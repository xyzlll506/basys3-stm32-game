Commands (choose build directories outside the source folder if desired):
  vivado -mode batch -source sim.tcl -tclargs <simulation-project-directory>
  vivado -mode batch -source build.tcl -tclargs <bitstream-output-directory>

create_project.tcl creates a normal .xpr project for GUI use.
build.tcl builds in a single process and never opens a hardware target.
Only constraints/board_link.xdc is added to the project by the scripts.
