# FPGA 游戏原型验证

验证日期：2026-10-27。目标为 Basys 3 / `xc7a35tcpg236-1`，使用 Windows 上的 Vivado / XSim 2018.3。

## 已完成

- `tb_game` 以 25.2 MHz 时钟和实际 UART 位时间运行，发送并解码真实串行数据。
- 覆盖四字节按键请求、十二字节状态回复、字节顺序、XOR、序号、保留字段、坐标范围、未定义 flags、数据中 A5/5A、8 ms 半包超时、停止位错误、复位恢复和 60 帧链路过期。
- 确认状态仅在下一次垂直消隐开始提交，接收完成时不立即改当前画面坐标。
- VGA 每帧 420000 个像素时钟；有效像素 307200，HS 低电平 50400 个时钟，VS 低电平 1600 个时钟，每帧一个消隐起点脉冲。
- 消隐强制 RGB 为黑色，仿真导出实际 renderer 的 640×480 PPM 画面。
- 按键同步和去抖测试通过：短脉冲拒绝，稳定按下及松开接受。测试缩短去抖计数，硬件值为 126000 个像素时钟（5 ms）。
- 完成综合、布局布线、DRC、时序检查及 BIT 生成。

| 项目 | 结果 |

| DRC | 0 violations |
| 内部 setup WNS | +30.868 ns |
| 内部 hold WHS | +0.122 ns |
| Slice LUT | 541 / 20800 |
| Slice registers | 565 / 41600 |
| BRAM | 0 |
| MMCM | 1 |
| 像素时钟报告周期 | 39.683 ns，约 25.2 MHz |
